# Roadmap

The roadmap is intentionally capability-oriented rather than date-oriented.

## Parser

- combined short flags
- negatable flags
- variadic positional arguments
- aliases
- richer option constraints

## Command tree

- nested commands and groups
- scoped middleware
- inherited global options
- lazy command loading

## Runtime

- injectable I/O for deterministic tests
- process execution
- HTTP client helpers
- credential storage adapters
- lifecycle cleanup hooks

## Tooling

- shell completion generation
- command schema introspection
- Markdown documentation generation
- machine-readable structured output
- test harness for stdin/stdout/stderr and fake runtime services
