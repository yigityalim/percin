# Code of Conduct

Percin is an open-source project. Participation in project spaces requires professional, respectful collaboration.

## Expected behavior

- Be precise and constructive when reviewing code or ideas.
- Critique technical work, not people.
- Respect different experience levels, backgrounds, and communication styles.
- Accept reasonable maintainer decisions about scope, architecture, and moderation.
- Disclose conflicts of interest when they are relevant to a contribution or review.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized conduct, sustained personal attacks, deliberate disruption, or publishing another person's private information are not acceptable.

## Enforcement

Maintainers may edit or remove content, close or lock threads, reject contributions, or restrict participation when conduct violates this policy. Serious platform abuse should also be reported through GitHub's abuse-reporting mechanisms.

For a private conduct report, contact the maintainers using the contact method published on the GitHub organization profile. Reports should include enough context to investigate and will be handled as confidentially as practical.
