# Security Policy

## Supported versions

Until Percin reaches 1.0, security fixes are provided for the latest published minor line only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub private vulnerability reporting for this repository. Include:

- affected version or commit
- impact and attack preconditions
- reproduction steps or proof of concept
- suggested mitigation, if known

Maintainers will acknowledge valid reports, coordinate remediation, and publish an advisory when appropriate. Please avoid public disclosure until a fix or coordinated disclosure plan exists.

## Supply-chain policy

Releases are intended to be published from GitHub Actions through npm trusted publishing with OIDC. Long-lived npm publish tokens are not part of the normal release path.
